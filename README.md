# ⚡ MarketWhy · 行情为什么动

> 看大盘哪里动了，以及当时发生了什么：检测 A 股、港股、美股、日韩欧、黄金原油汇率美债的盘中异动，自动匹配同时段的中外财经快讯作为可能原因；聚合多家媒体同时报道的「影响市场的大事」

**🌐 在线访问：[https://climb0516.github.io/market-why/](https://climb0516.github.io/market-why/)**

姊妹站：[Market Board 行情看板](https://climb0516.github.io/market-board/)（行情细节）· [MarketCal 财报与宏观日历](https://climb0516.github.io/earnings-calendar/)（接下来会发生什么）

## 功能

**总览**
- 顶部行情条：15 个品种的最新价、涨跌幅、当日分时，⚡N 表示今天检测到 N 段异动；点击进入该品种的异动归因
- 今日异动：按「幅度 ÷ 阈值」挑出最显著的 14 段，每段列出最相关的 2 条新闻
- 影响市场的大事：近 24 小时多家来源报道的相近消息合并成一条，点开看各家原文
- 因素热度：近 24 小时重要新闻按因素计数（货币政策、宏观数据、地缘冲突、政策政治、AI 科技、财报公司、大宗商品、汇率），点击跳到对应快讯

**异动归因**
- 分时图上用不同颜色标出每段异动，编号与下方列表对应，鼠标悬停看时间、点位、涨跌
- 每段异动展开后列出可能原因：时间、来源、因素标签、摘要，点击跳原文
- 开盘跳空单独列出，看休市期间（前 12 小时）的消息

**快讯**
- 中外快讯按时间合流，保留 48 小时；可按 全部 / 中文 / 海外、只看重要、因素标签筛选，支持搜索（按 `/` 聚焦）
- 重要快讯标红点（各来源自己的重要标记：见闻 score≥2、东财标红、同花顺标红、新浪「焦点」、格隆汇 level≥1）

右上角：📡 来源状态、📊 Market Board、📅 财报日历、☾ 深浅色切换。地址栏 hash 记录当前视图（`#market/100.N225/0`、`#feed/geo`），可直接分享。页面每 5 分钟重新读取一次数据。

## 异动检测与归因

**品种与阈值**（`scraper.py` 里的 `MARKETS`，30 分钟内涨跌超过阈值算异动）

| 分组 | 品种（阈值） |
|---|---|
| A股 | 上证指数 0.5%、创业板指 0.8% |
| 港股 | 恒生指数 0.6%、恒生科技 0.9% |
| 美股 | 纳斯达克100 0.6%、标普500 0.5%、纳指期货 0.5% |
| 亚太欧 | 日经225 0.7%、韩国KOSPI 0.8%、德国DAX 0.6% |
| 商品汇率 | 伦敦金 0.6%、布伦特原油 1.0%、美元指数 0.3%、美元/离岸人民币 0.2%、美债10年收益率 4bp |

**检测**：对每个分时点回看 30 分钟找涨跌最大的起点，超过阈值的段同方向合并，起止点收紧到区间极值；再按幅度从大到小保留，和已保留段重叠超过一半的丢掉，每个品种最多 6 段。开盘价相对昨收超过阈值算「开盘跳空」。

**归因打分**：取异动开始前 25 分钟到结束后 10 分钟的新闻（跳空取前 12 小时）：

```
分数 = 市场相关词命中数 × 2 + 因素权重 + 重要度 × 1.5 + 时间接近加分（最多 1.5） − 行情播报降权 2.5
```

- 市场相关词：每个品种一组（如日经：日经 / 日本 / 日元 / BOJ / 软银 / 芯片…），英文词加词边界，`AI`、`CPI` 这类缩写区分大小写
- 跳空时本市场词没命中的，用美股 / 全球风险词按一半权重算（A股、港股的跳空常常是外盘带的）
- 因素权重：货币政策、宏观数据、地缘冲突 3；政策政治、AI 科技、大宗商品、汇率 2；财报公司 1
- 「恒指收跌 1%」「日内跌超 2%」这类行情播报是结果不是原因，降权
- 分数 ≥ 3 的取前 6 条，标题相近的去重

**今日大事**：近 24 小时重要度 ≥ 1 的新闻，不同来源标题相近（中文按二字词重合，英文按单词重合，时间相差 8 小时内）的合并：

```
分数 = min(中文来源数, 3) × 1.5 + 海外来源数 × 2 + 重要度 × 1.5 + 因素权重 × 1.5 + min(市场词数, 4) − 行情播报 5
```

只有一家报道且不是重要快讯的、没有因素也没有市场词的不进列表。国内各家互相转载很普遍，所以中文来源数封顶 3。

> 这是相关性提示，不是因果判断。规则调整直接改 `scraper.py` 里的 `MARKET_KW`、`FACTORS`、`RESULT_RE`；每次运行都会对 48 小时内的全部新闻重新打标签，改完立即生效。

## 数据结构（data.json）

```
{
  "updated": "2026-11-06T16:41:00+08:00",
  "factors": [{"key": "monetary", "name": "货币政策", "weight": 3}, …],
  "sources": [{"id", "name", "region", "abbr", "color", "paywall", "ok", "count", "error"}],
  "markets": [{
    "id": "100.N225", "name": "日经225", "group", "th", "unit": "%|bp",
    "pre", "last", "dec", "chg",
    "pts": [[ts, price], …],            // 最多约 240 点，异动起止点保留
    "moves": [{"start", "end", "from", "to", "chg", "dir", "kind": "swing|gap",
               "news": [{"id", "score"}]}]
  }],
  "events": [{"id", "title", "summary", "ts", "factors", "imp", "result", "score", "refs": [newsId]}],
  "news": [{"id", "src", "title", "summary", "url", "ts", "imp": 0-2, "lang": "zh|en",
            "factors": [...], "result": bool, "est"?: true}]
}
```

新闻 id 是 `来源 + 标题` 的 FNV-1a 哈希，稳定不变；每次运行和上一份合并，保留 48 小时。

## 更新频率

GitHub Actions（`.github/workflows/scrape.yml`）：

- 工作日（UTC 周一到周五）每 15 分钟，第 7 / 22 / 37 / 52 分钟
- 周末每小时第 7 分钟
- 改了 `scraper.py` 或 workflow 推送后自动跑一次；也可以在 Actions 页手动触发
