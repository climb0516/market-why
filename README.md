# ⚡ MarketWhy · 行情为什么动

> 看大盘哪里动了，以及当时发生了什么：检测 A 股、港股、美股、日韩欧、黄金原油汇率美债的盘中异动，自动匹配同时段的中外财经快讯作为可能原因；聚合多家媒体同时报道的「影响市场的大事」；全球经济数据、产业主题、有色金属、AI 产业链一页看完，每个主题都能点进去看相关股票和个股详情

**🌐 在线访问：[https://climb0516.github.io/market-why/](https://climb0516.github.io/market-why/)**

姊妹站：[Market Board 行情看板](https://climb0516.github.io/market-board/)（行情细节）· [MarketCal 财报与宏观日历](https://climb0516.github.io/earnings-calendar/)（接下来会发生什么）

## 设计

2026-11-06 改版：在 `design/` 的五款样张里选了 E（参考 Perplexity 的带来源总结 + Finviz 的主题热力图 + TradingView 的配色），手机上借用 A 款的大数字卡片和底部标签栏。

- 配色：TradingView 深色（背景 `#0f1218`、面板 `#171b24`、强调蓝 `#2962ff`、涨 `#f23645`、跌 `#089981`），右上角可切浅色
- 图标：界面按钮和导航用线性 SVG（`index.html` 里的 `I` 图标表）；行业格子按参考截图用 emoji（`themes.json` 的 `icon` 字段），一眼能认出是哪个行业
- 涨跌：文字用红涨绿跌；表格和标签用彩色涨跌块；热力图颜色按 ±6% 分档
- 导航：电脑顶部横向标签；手机（≤ 860px）底部标签栏：总览 / 全球 / 有色 / AI / 快讯，异动归因从总览和行情条进入
- 电脑和手机显示的数据完全一样，只是每行放几个格子不同（电脑 4～6 个，手机 2 个）
- `design/` 目录保留五款样张备查（它们用 `themes.json` 里原来的 emoji `icon` 字段）

## 功能

**总览**
- 顶部行情条：15 个品种的最新价、涨跌幅、当日分时，「N 异动」表示今天检测到 N 段异动；点击进入该品种的异动归因
- 今日市场总结：按规则从行情和新闻拼出 6 条（美股 / 亚太 / A股港股 / 产业主题 / 大宗与避险 / 最受关注事件），每句带引用编号，底部列出来源卡片，点击进入站内新闻详情；不是 AI 撰写
- 今日异动：按「幅度 ÷ 阈值」挑出最显著的 8 段，左侧涨跌块、右侧最相关的新闻；「全部」进入异动归因
- 全球产业热力图：12 个产业主题，块内股票方块大小 = 美元市值（汇率近似），颜色 = 今日涨跌；点主题名进主题页，点方块进个股页
- 影响市场的大事：近 24 小时多家来源报道的相近消息合并成一条，点开看各家原文
- 因素热度：近 24 小时重要新闻按因素计数（货币政策、宏观数据、地缘冲突、政策政治、AI 科技、财报公司、大宗商品、汇率），点击跳到对应快讯

**全球 / 有色 / AI**（主题和成分股在 `themes.json` 里配置）
- 全球：全球经济数据（布伦特原油、恐慌指数 VIX、美元强弱、美债长债 TLT、黄金、白银、铜、天然气）；全球产业数据 12 个主题（AI 算力、CPO、半导体、存储、数据中心、云计算、商业航天、卫星、机器人、自动驾驶、核电、稀土），右上角显示美股交易状态
- 有色：金银、工业金属（沪金 / 沪银 / 沪铜 / 沪铝 / 沪锌 / 沪镍 / 沪锡主连），其他金属（钨、钼为 A 股板块指数；锗、铟、锑为相关股票篮子）
- AI：AI 产品价格（云算力、Token）、AI 设备价格（DRAM、NAND、HBM、SSD、光模块、光纤、PCB、MLCC、GPU、CPU、先进制程、封装、电力、电力设备、散热、算力租赁），成分股横跨美、港、A、日、韩、台
- 主题涨跌幅：有对应期货的用期货涨跌，有板块指数的用板块指数，其余按成分股**等权平均**
- 页面从上到下：行情格子（「名称 / 价格 ▲▼涨跌」）→ 行业格子（「图标 行业名 ▲▼涨跌」，点进去是该行业的股票）→ 最后是本页所有行业的产业热力图（看行业里具体哪只股票在涨跌）
- 点主题进入主题详情：期货 / 板块的当日分时、成分股热力图、相关股票按涨跌排序（价格、涨跌块、按上市地货币显示的市值）、快讯库里按主题关键词匹配的相关快讯
- 点股票进入个股详情：价格与指标（今开、最高、最低、昨收、成交额、总市值、市盈率、换手率）、分时 / 日K / 周K / 月K、所属主题、东方财富 F10 公司简介（美、港、A 股；日韩台个股没有）、相关快讯
- 行情由浏览器直连东方财富，30 秒刷新；接口不可用时用 `data.json` 里的快照兜底。恐慌指数只能由爬虫从 CBOE 取（浏览器跨域不允许），约 15 分钟更新
- 「云算力」「Token」没有公开的价格指数，用相关公司股票篮子代替，页面上有说明

**新闻详情**（`#news/<id>`）
- 站内所有快讯（总览、大事、异动归因、快讯流、主题页、个股页）点击都先进入站内详情页
- 中文快讯显示全文（快讯本身就是全文，不截断）；海外媒体 RSS 只有标题和摘要，注明「全文在原站（🔒 收费）」
- 发布后的行情：相关品种从发布时刻到 30 分钟后的变化（只有最近一个交易日有分时，更早的不显示）
- 被列为哪些异动的可能原因、同一事件的其他报道、相关主题
- 原文：东方财富、同花顺、华尔街见闻、格隆汇的文章页允许内嵌，详情页下方直接显示原站页面（图片、排版都在），并有「新窗口打开」兜底；新浪的快讯没有单条文章页，海外媒体禁止内嵌或要人机验证（实测 Bloomberg 拒绝、WSJ / MarketWatch 弹验证、路透 / FT / BBC / CNBC / 日经 / SCMP / Investing 设置了禁止内嵌），只给「阅读原文」按钮
- 不转存原文和配图：公开站点完整转载有版权问题，收费媒体的正文也不应绕过收费墙

**异动归因**
- 分时图上用不同颜色标出每段异动，编号与下方列表对应，鼠标悬停看时间、点位、涨跌
- 每段异动展开后列出可能原因：时间、来源、因素标签、摘要，点击跳原文
- 开盘跳空单独列出，看休市期间（前 12 小时）的消息

**快讯**
- 中外快讯按时间合流，保留 48 小时；可按 全部 / 中文 / 海外、只看重要、因素标签筛选，支持搜索（按 `/` 聚焦）
- 重要快讯标红点（各来源自己的重要标记：见闻 score≥2、东财标红、同花顺标红、新浪「焦点」、格隆汇 level≥1）

右上角：📡 来源状态、📊 Market Board、📅 财报日历、☾ 深浅色切换。地址栏 hash 记录当前视图（`#global`、`#theme/dram`、`#stock/105.NVDA`、`#market/100.N225/0`、`#feed/geo`），可直接分享；主题和个股是「进入」的下一层，浏览器返回键能回到上一页。页面每 5 分钟重新读取一次数据。

## 异动检测与归因

**品种与阈值**（`scraper.py` 里的 `MARKETS`，30 分钟内涨跌超过阈值算异动）

| 分组 | 品种（阈值） |
|---|---|
| A股 | 上证指数 0.5%、创业板指 0.8% |
| 港股 | 恒生指数 0.6%、恒生科技 0.9% |
| 美股 | 纳斯达克100 0.6%、标普500 0.5%、纳指期货 0.5% |
| 亚太欧 | 日经225 0.7%、韩国KOSPI 0.8%、德国DAX 0.6% |
| 商品汇率 | 伦敦金 0.6%、布伦特原油 1.0%、美元指数 0.3%、美元/离岸人民币 0.2%、美债10年收益率 4bp |

**检测**：对每个分时点回看 30 分钟找涨跌最大的起点，超过阈值的段同方向合并，起止点收紧到区间极值；再按幅度从大到小保留，和已保留段重叠超过一半的丢掉，每个品种最多 6 段。开盘价相对昨收超过阈值算「开盘跳空」。

**归因打分**：取异动开始前 25 分钟到结束后 10 分钟的新闻（跳空取前 12 小时）：

```
分数 = 市场相关词命中数 × 2 + 因素权重 + 重要度 × 1.5 + 时间接近加分（最多 1.5） − 行情播报降权 2.5
```

- 市场相关词：每个品种一组（如日经：日经 / 日本 / 日元 / BOJ / 软银 / 芯片…），英文词加词边界，`AI`、`CPI` 这类缩写区分大小写
- 跳空时本市场词没命中的，用美股 / 全球风险词按一半权重算（A股、港股的跳空常常是外盘带的）
- 因素权重：货币政策、宏观数据、地缘冲突 3；政策政治、AI 科技、大宗商品、汇率 2；财报公司 1
- 「恒指收跌 1%」「日内跌超 2%」这类行情播报是结果不是原因，降权
- 分数 ≥ 3 的取前 6 条，标题相近的去重

**今日大事**：近 24 小时重要度 ≥ 1 的新闻，不同来源标题相近（中文按二字词重合，英文按单词重合，时间相差 8 小时内）的合并：

```
分数 = min(中文来源数, 3) × 1.5 + 海外来源数 × 2 + 重要度 × 1.5 + 因素权重 × 1.5 + min(市场词数, 4) − 行情播报 5
```

只有一家报道且不是重要快讯的、没有因素也没有市场词的不进列表。国内各家互相转载很普遍，所以中文来源数封顶 3。

> 这是相关性提示，不是因果判断。规则调整直接改 `scraper.py` 里的 `MARKET_KW`、`FACTORS`、`RESULT_RE`；每次运行都会对 48 小时内的全部新闻重新打标签，改完立即生效。

## 主题配置（themes.json）

```
{
  "tabs": [{"key": "global", "name": "全球", "sections": [
     {"title": "全球经济数据", "kind": "quote", "items": [{"id": "112.B00Y", "name": "布伦特原油"}, …]},
     {"title": "全球产业数据", "kind": "theme", "session": "us", "items": ["ai-compute", …]}]}, …],
  "themes": {
    "copper": {"name": "铜", "icon": "🟠", "ico": "ingot", "kw": "铜价|沪铜|伦铜|copper|铜矿",   // ico：页面用的线性图标名；icon：样张用的 emoji
               "quote": "113.cum",            // 可选：主题涨跌直接用这个品种
               "board": "90.BK1625",          // 可选：A 股板块指数
               "note": "…",                   // 可选：页面上的说明
               "stocks": ["105.FCX", "1.601899", …]}
  },
  "names": {"105.FCX": "自由港麦克莫兰", …}   // 行情还没回来时显示的名称
}
```

代码用东方财富 secid：`105/106/107` 美股（纳斯达克 / 纽交所 / 美交所），`116` 港股，`1` 沪市，`0` 深市，`176` 日股，`177` 韩股，`178` 台股，`113` 上期所，`122` 现货贵金属，`90.BK` A 股板块。改完推送即可，爬虫会一起更新快照。`kw` 里的英文词自动加词边界，全大写缩写区分大小写。

## 数据结构（data.json）

```
{
  "updated": "2026-11-06T16:41:00+08:00",
  "factors": [{"key": "monetary", "name": "货币政策", "weight": 3}, …],
  "sources": [{"id", "name", "region", "abbr", "color", "paywall", "ok", "count", "error"}],
  "markets": [{
    "id": "100.N225", "name": "日经225", "group", "th", "unit": "%|bp",
    "pre", "last", "dec", "chg",
    "pts": [[ts, price], …],            // 最多约 240 点，异动起止点保留
    "moves": [{"start", "end", "from", "to", "chg", "dir", "kind": "swing|gap",
               "news": [{"id", "score"}]}]
  }],
  "events": [{"id", "title", "summary", "ts", "factors", "imp", "result", "score", "refs": [newsId]}],
  "quotes": {"105.NVDA": {"name", "price", "pct", "chg", "amt", "turn", "pe", "pb", "high", "low", "open", "prev", "cap", "ind", "time"}, "cboe.VIX": {…}},
  "news": [{"id", "src", "title", "summary", "url", "ts", "imp": 0-2, "lang": "zh|en",
            "factors": [...], "result": bool, "mk": [相关行情品种 id], "est"?: true}]
}
```

新闻 id 是 `来源 + 标题` 的 FNV-1a 哈希，稳定不变；每次运行和上一份合并，保留 48 小时。
